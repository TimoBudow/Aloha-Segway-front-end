# Static Site Scope

The project has been narrowed to a clean landing page that sends booking traffic to FareHarbor.

## In Scope

- Single-page React site
- Mobile and desktop responsive layout
- Config-driven tour content
- Tour hazards and safety expectations
- Route-preview map graphics
- Gallery images
- Reviews/testimonials
- Social links
- FareHarbor booking CTAs
- Static Vercel deployment

## Out Of Scope

- Custom booking flow
- Custom payment collection
- Owner/admin dashboard
- Database
- Customer accounts
- Automatic FareHarbor booking creation
- Public exposure of FareHarbor customer/calendar data

## Future Options

- Replace placeholder images with owner-approved photos.
- Replace placeholder reviews with verified public reviews.
- Add FareHarbor embedded booking buttons if the owner wants that flow.
- Add a CMS or image storage only if the owner commits to maintaining content.
